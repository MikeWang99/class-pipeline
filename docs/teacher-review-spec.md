# 教学优化复盘规范

这份复盘写给授课教师本人，不写给学生或家长。它是课后反馈完成后的最后一步，目标是帮助教师持续改进课堂，而不是评价教师个人。

## Evidence-first

生成前必须完整读取：

- 本次课完整课堂文字稿；
- 本次课完整学生档案；
- 最近一次正式课后反馈；
- 本文件。

只把课堂中能观察到的内容写成判断。优先使用时间段、重复出现的表达、实际提问与回答、概念转折、例题讲解顺序和学生反应作为证据。文字稿明显失真、重复或说话人不清时，不把它当作教师行为证据；应在“证据边界”中说明。

不要把一次口误、一次重复或 Whisper 的错转直接定义为长期问题。长期问题必须满足以下至少一项：

- 在多次课堂记录中重复出现；
- 本节课在多个独立片段中出现；
- 对学生理解、课堂节奏或答案质量产生了明确影响。

## 输出位置

每节课写入：

`{vault}/上课记录/教学优化/{YYYY-MM-DD} {体系} Class-{学生}-教学优化.md`

同时维护：

`{vault}/上课记录/教学优化/教学优化总览.md`

总览只保留跨课堂仍然成立的长期问题、当前优先级和历次复盘链接；不要把每节课的全部细节重复粘贴进去。

## 固定结构

每节课的文件使用以下标题，标题不要加粗：

`本节课教学优化复盘：`

`「1. 本节课做得有效的地方」`

`「2. 本节课最值得改进的地方」`

`「3. 可执行的改进动作」`

`「4. 长期跟踪问题」`

`「5. 证据边界」`

要求：

- 第 1 节最多 2 个要点，写清哪些讲解、例子、提问或课堂决策有效，以及它为什么帮助了学生。
- 第 2 节最多 3 个要点，优先检查：语气词和重复表达、概念是否讲透、推理是否跳步、课堂结构与节奏、提问是否暴露理解、纠错和总结是否及时。必须结合本次课证据，不能泛泛评价。
- 第 3 节把问题改写成下节课可执行的动作，例如“讲完定义后先用一句话说明物理量和方向，再进入公式”，不要只写“注意表达”或“加强逻辑”。
- 第 4 节只保留需要跨多节课观察的教师问题，并说明当前状态；一次性问题放在第 2 节，不放入长期台账。
- 第 5 节说明转写质量、说话人辨识和哪些结论不能确认。不能为了完整而猜测。

## 写作风格

- 直接、具体、专业，语气诚实但不羞辱；指出问题后必须给改法。
- 不使用“你讲得很差”“不够专业”这类人格化判断。
- 不把学生的困难直接归因于教师；只分析教师可观察、可调整的课堂行为。
- 不写未经课堂证据支持的教学理论或泛泛赞美。
- 不把家长反馈复制过来，也不生成学生作业或学习结论。
- 复盘默认 400–700 字；证据不足时可以更短。
